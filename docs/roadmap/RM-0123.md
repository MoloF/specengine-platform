# auto-runner (release auto-mode, 0.47.0): the plugin's `autopilot.sh` drives a pack overnight

A POSIX shell script in the plugin, outside `spec`. `spec`, MCP and the daemon start no agent. The script loops: `spec auto next`, a worktree per task from the integration branch, outside the repository, then `claude -p "/specengine:feature <T>"` to plan. Next comes `spec auto approve`, the same skill to implement, and `spec auto land`.

It never skips permissions: `--permission-prompts none` turns a missing allow rule into a denial, which holds the task and names the tool. It classifies each leg by its `stream-json` result, never its exit code. It pauses on a usage limit and has lanes, a stop file, `--until` and caps. The skill is unchanged.

Tested with a fake `claude` on `PATH`; one live run is the owner's gate. Spec: `docs/features/auto-runner.md`. After RM-0122's command contract.

Shipped 2026-11-15 in `auto-mode` (plugin 0.47.0): `plugin/specengine/scripts/autopilot.sh`. Canon: `docs/canon/auto-runner.md`. Owed: RN0, the owner's live run (gate G4).
