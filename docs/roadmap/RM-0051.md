# hub-git (Phase 7, step 10): sole writer, merge and push, the index in the commit

The hub is the sole writer of a brief zone on a sparse clone (`docs/` and `specengine.toml`) of the game's own repository. It merges and pushes, never rebases, because the queue stores `applied_commit`; a failed push shows on screen and retries; the index travels in the apply commit. Hub and local `PR-` numbers can collide in `Proposal:` trailers, so the hub takes a separate range or a qualified trailer. Issues `apply-outputs` (`docs/features/roadmap-items.md`, N12). No `crates/*/src` runs git's `push`, `pull` or `fetch` today. This step begins at the first network verb: from `hub-confirm` (RM-0050) on, a confirm already commits in the hub's checkout, so this step has its caller, and until it ships `applied` means committed on that hub. 4-6 pipeline hours.
