# card-store (Phase 7, step 4): cards, flows per discipline, events, CLI and MCP tools

Cards `C-NNNN` in the queue database (ADR-0056). Reused from tasks: a pure `transition`, here driven by config, the compare-and-set `revision`, `events`, criteria, caps. Fields: flow, column, title, goal, targets, snapshot, assignee, reviewer, discipline, estimate, due, parent, `corrects`, evidence. A manual card has no targets, and a row lists cards with no node. Reads carry no clock, so `due` is served raw. A `C` in `[ids]` is refused as `PR` and `T` are (`prefix_clash`, `task_prefix_clash`). A full card cycle leaves `git status` empty, makes no commit and writes one event per change; a move outside the flow exits 1 naming the allowed moves. Spec: `docs/features/card-store.md`. 4-6 pipeline hours.
