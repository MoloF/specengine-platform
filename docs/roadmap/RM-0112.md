# corpus-map (Phase 7, the writer map): the whole corpus as one map

The owner chose the whole corpus on 2026-11-13 ("the whole corpus at once"), like Obsidian's global graph. He knew it needs a layout engine, a new dependency and an ADR.

`spec map` and the daemon's map route serve every live node with its resolved edges, use counts and orphan flag, plus the unresolved targets. The Graph section's home draws them: force-directed, sized by use, coloured per kind with a label, orphans marked. Hovering lights a node's neighbours, a click opens the document, and a search focuses. The filters he chose that day come with it: only broken, only orphans, ghost nodes, kind chips, a fixed colour per kind. `spec graph` gains `--both` and `--kind`, and the local graph a Both ways mode.

ADR-0080 sets the layout: `d3-force` on a 2D canvas, in a lazy chunk. Spec: `docs/features/corpus-map.md`. **Shipped 2026-11-13** with RM-0113, no plugin version; canon `docs/canon/spec-map.md`.
