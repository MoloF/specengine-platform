# Load flake: `failing_test_removes_evidence` hits its 1 s nested timeout

`failing_test_removes_evidence` in `crates/specengine-cli/tests/verify_tests_lock.rs` sets `[verify] timeout = 1` for its time-out half, so its nested test runs have 1 s each and can hit it under full parallel load. Seen once in a full run on 2026-10-30; 3 of 3 passes alone. Not drafted.
