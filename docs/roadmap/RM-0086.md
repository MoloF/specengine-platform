# role-dashboards (Phase 7, v4 step 4): Overview per workspace

Today's Overview holds two blocks, Tasks and Inbox, that duplicate other pages. Each workspace gets a dashboard built only from counts the daemon serves:
- a writer's: open questions, cards returned to them, gaps;
- a developer's: work in progress, reviews waiting, tasks awaiting the owner, drift on their modules;
- a lead's: release health, returned hand-offs, decision age, collisions.

A writer's dashboard never triggers `health`, which builds the code index inside the project's turn. 4-6 pipeline hours.
