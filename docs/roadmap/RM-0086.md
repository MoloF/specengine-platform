# department-overview (Phase 7, v5 step 12): an Overview per department, counted by status category

Today's Overview holds two blocks, Tasks and Inbox, both copies of other pages. Each department gets an Overview built only from counts the daemon serves. The counts are by RM-0093's status category across the department's flows (to do, in progress, done, returned), so different flows stay comparable.
- **A writer's department:** open questions on its tasks (RM-0097), subtasks returned to it, gaps.
- **A developer's department:** work in progress, reviews waiting, agent tasks awaiting the owner, drift on its directions.
- **A lead's view:** every department side by side, parents ready to accept (RM-0098), returned hand-offs, decision age, collisions.
