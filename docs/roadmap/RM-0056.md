# change-record (Phase 7, step 14): what a change invalidated, cost and who accepted it

A `CR-` file per change names its consequences, the estimate delta and who accepted it: class `spec`, `status: shipped`, so Tier 3 from birth with no cap. It is built from the commit trailers, `spec impact` and the accepted cards, shown as a preview before it is written. A baseline takes one confirm over a shown changeset: each proposal its own commit, then a `CR-` and a git tag. Issues `changeset`, which amends ADR-0038 (owner's decision 12). RM-0035 and RM-0036 move into this slice. From `trace-truth` (RM-0066): `card.cleared`'s `from` and `to` hold a target's `within_hash`, its `rev` the target's own, so a nested change leaves `rev` where it was and a `Revision:` join for it must walk `within` of the target. 4-6 pipeline hours.
