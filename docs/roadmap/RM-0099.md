# design-sweep (Phase 7, v5 step 7): every other screen on the foundation

RM-0093 builds the tokens, themes, guards and primitives and applies them to the shell, the Board and the task. Flow is RM-0094's and the document modal RM-0095's. This sweep takes the rest, in two slices of the UI lane after RM-0103 `canvas-clicks` (08 s2 Phase 7, "Owner's word, 2026-11-12"), 11-15 pipeline hours (its analysis of 2026-11-12):
- **`design-sweep`** (a), 6-8: the rename of all 698 legacy-name uses and the raw weights, the aliases out, the guards; Inbox, Questions and the Spec tree on primitives; the Overview renamed only (RM-0086 replaces it); shipped 2026-11-12 (`docs/canon/ui-design.md`);
- **`design-sweep-b`** (b), 5-7: Health, Graph, Roadmap and Agent tasks on primitives, the last exceptions, the header heights; specced (`docs/features/design-sweep-b.md`).

- **Primitives.** Each screen takes Button, Lozenge, PropertyList, Breadcrumbs where it has a path, EmptyState for its empty states, and the work-item layout where it shows one item.
- **Legacy tokens.** Each use of `--font-size-s|m|l|xl`, `--line-height-tight` and `--space-1..6` is renamed to its scale step, so the aliases leave `tokens.css`. The guard then refuses those names, and font weights take their tokens.
- **Exceptions.** Every exception that names this item leaves RM-0093's exceptions list.
- **The looks.** Both themes and both languages are checked at 1440x900 and 1100x800 with RM-0093's DevTools measure.
