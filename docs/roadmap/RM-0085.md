# board-handoff (Phase 7, v4 step 3): a static board, a card modal, hand-off and return, tasks inside cards

A board like Jira's: columns that never shift, and swimlanes by assignee or parent with an "Everything else" lane. A plain click opens a card in a modal; Cmd-click opens its own page through a native link on a card route. The tabs come from the chosen workspace's card flows. 8-12 pipeline hours. It may issue `card-handoff`.

- **Hand-off.** A hand-off is a child card (`--parent`) in the receiving discipline's flow. The receiver takes it with a move (Q7).
- **Return.** A return is a move to a configured column, with a reason. That needs a note on a move, so the command changes.
- **Acceptance.** Accepting the result stays the requesting side's act (ADR-0056); the hand-off needs a word other than "accept".
- **Tasks inside cards.** An agent task shows inside its card (the owner's decision 3), through a card-to-`T-` link that no gate reads. This is phase two's `card-task-link`.
