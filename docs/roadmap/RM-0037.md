# evidence-level: each node's evidence level, computed per read

05 s5.5 defines the levels: 1 a passing bound test, 2 a machine assertion, 3 a fresh binding, 4 an audit verdict, 5 prose only, or `non_verifiable`. Each node also carries its own `needs:` requirement. The level would be computed per read and shown in the UI and the bundle. The tested-evidence slices left it out (`docs/features/tested-reads.md` "Out of scope"). It was moved out of RM-0011's scope on 2026-10-21 (Q-N). Not drafted.
