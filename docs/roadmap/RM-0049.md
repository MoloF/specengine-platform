# hub-identity (Phase 7, step 8): a public origin, an identity header, a person in `Author`

Hub mode of `specengine-http`; local `spec serve` keeps its defaults. A public origin (loopback `Host` and `Origin` are hard-coded today), one identity header from an external proxy on the same host, a person in `Author`, a `[team]` table. Issues `hub-mode`, which supersedes ADR-0017 and so reverses the single-user premise, and `hub-identity`, which supplements ADR-0034: no account, token or session inside SpecEngine, the daemon trusting that one header, and no agent running on that host. A write with no identity is refused, and two identities give two `Decided-by` values. 4-6 pipeline hours.
