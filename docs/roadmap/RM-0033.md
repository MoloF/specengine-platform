# lock-diff: what changed since the lock, beside a drifted binding

For each binding whose row has a `spec.lock` entry, this shows the node's text at the entry's `commit` and the bound code at its `file_blob`, each against the working tree, as git's hunks. The owner then sees what moved before deciding. Sources: the `conflict` row of 05 s5.3, 06 s4, and `docs/canon/spec-lock.md` "Entry". It was moved out of RM-0011 on 2026-10-21 (Q-A).

First comes a new decision record adding to ADR-0046, because hunks inside a read go against `docs/canon/architecture-code.md` "Sync in reads" (git is read only, never `diff`). Then two slices:
- `lock-diff`: the record and its canon, `spec lock diff REF [--json]`, the daemon's `lock-diff?ref=`, the key sets and the UI's types;
- `lock-diff-ui`: an on-demand panel in the node's Bindings tab.

Not drafted.
