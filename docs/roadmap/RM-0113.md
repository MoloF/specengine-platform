# scope-rings (Phase 7, the writer map): nodes on concentric rings, the radius their scope

The owner chose this on 2026-11-13, an extra beside the writer map, taken from an earlier prototype's rings. Each ring is a scope layer, the widest inside. A ring's nodes are sectors at equal angles, each filled by its work state. Search dims the rest, state chips filter, and a click opens the node. A legend and a List go with them.

The core knows no domain (ADR-0008), so the layers are the project's `[[map.ring]]` rows. Each picks its nodes by a root, kinds, or both, as a module does. The view is plain SVG, with no dependency and no ADR.

Spec: `docs/features/scope-rings.md`. **Shipped 2026-11-13** with RM-0112, no plugin version; canon `docs/canon/spec-rings.md`. It shares the Graph section's home with RM-0112.
