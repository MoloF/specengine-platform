# usage-orphans (Phase 7, the writer map): what uses a document, and which documents nothing links

This item comes from the owner's goal of 2026-11-13. Writers describe documents and reuse props and mechanics through links, and they should see what is used where, by which documents and in which places. Orphan documents should show up, so they can be deleted or brought in later.

His answer that day defines an orphan: linked to nothing, by no link in either direction and no child. The analyst's slice 1 adds the "filled by" panel from an earlier prototype.

One count, computed per read and never stored, is served in four places:
- the document view's Links, grouped by kind with each place;
- a "Used by" column and a "Used by 0" filter in a direction's catalog;
- an `orphans` row in Health;
- `get_node`, at plugin 0.46.0.

Spec: `docs/features/usage-orphans.md`, no ADR, 8-12 pipeline hours. It comes first among the writer map's items: RM-0112 sizes its map by this count.
