# collision-pass (Phase 7, v5 step 9): candidates, a pair ledger, a skill

Candidates come from the graph (same kind sharing `uses`, a group or a term) plus search, at most N pairs. A ledger keyed by the two `norm_hash` values re-checks only changed pairs, so the cost follows changes, not n squared. An agent outside SpecEngine reads the pairs and files `report_discrepancy` with `gap_type: contradicts`; false positives are bounded by caps and the ledger. 5-8 pipeline hours (its analysis of 2026-11-12: the schema step and the second tool).
