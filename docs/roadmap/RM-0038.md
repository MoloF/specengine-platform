# task-stage: the owner's staging form `approve_task`

This stages the owner's task decision from the session, as RM-0012 does for a proposal. It adds task stage columns and events, has `spec task approve|changes T` show and confirm a staged choice on a terminal, and adds an `approve_task {task_id}` form (approve, or request changes with a note). Today a task's approval has no MCP tool (`docs/canon/architecture.md#control`, `docs/canon/tasks.md`), and ADR-0035 covers only a decision on an open proposal, so it needs its own ADR. It was split out of RM-0012 on 2026-10-22 (Q2). Not drafted.
