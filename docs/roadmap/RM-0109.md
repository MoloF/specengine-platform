# code-languages (Phase 7, pool, on a trigger): bind code in a second language

From the owner's vision of 2026-11-11 (08 s2 Phase 7, "Owner's vision, 2026-11-11"): the implementation, in Rust, Go or another language, is a second layer chosen per project, bound case by case. Markers and AST hashes in a language beyond Rust: its tree-sitter grammar, its marker comment form, its hash levels; 6-10 pipeline hours for the first language. It needs an ADR amending ADR-0010 (markers), ADR-0018 and ADR-0020 (tree-sitter, Rust first). It waits for a real project in that language and does not start before one exists.
