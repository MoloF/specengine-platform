# pack (Phase 7, step 19): `spec init --pack` and a config proposal

A template pack is files outside the core (ADR-0008): `[ids]` prefixes, `[[check.rules]]`, card flows, vocabulary in the project's language over an English interface (owner's decision 10). `spec init --pack` installs one. A writer's type change is a reviewed config proposal, since `specengine.toml` is no walked file. Three game fixtures and a non-game one guard against a word leaking into the core. 3-5 pipeline hours.

Deferred to the next release, `v4`, on 2026-11-04: the owner's instruction to do only what the hub's release to a server needs (08 s2 Phase 7, "Release scope").

Since 2026-11-08: v4 step 1a `workspaces` (RM-0081) ships the gamedev preset ahead of this step, as a fixture-tested file outside the core; `spec init --pack` and the config proposal stay here.
