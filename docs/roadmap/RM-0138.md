# reference-promotion (Phase 7, pool): an approved reference enters git beside its entity, through the one writing door

From the owner's accepted proposal of 2026-11-21: approved references are promoted into git (with LFS) beside the entity document (08 s2 Phase 7, "Owner's word, 2026-11-21/22"). It is slice 3 of three, 0.52.0, and comes after RM-0137.

**Decision to come, an ADR (number 0089, written with the slice's spec).** A reference enters git only through a `reference` proposal, applied by `apply_proposal` to a home that `[references]` names by `kinds`.
- LFS follows the project's `.gitattributes`. The hub image therefore ships git-lfs, which reverses `hub-deploy.md` "Image"'s "no git-lfs" and `hub-git.md`'s "LFS content in the cone is unsupported".
- A typed, uncounted `references:` key links the file to its entity, each entry `<path> | <what matters>`. Every card targeting the entity inherits it.
- `[auto]` never applies this kind.
- The core knows no kind or "location" (ADR-0008). The example homes are in the gamedev preset; the core's allowlist covers media types only, and a project may narrow it, never widen it.

**Surfaces:**
- the kind `reference` (schema 17 if it needs a blob column); `INDEX_FORMAT` 22, with each node's promoted references;
- `spec propose reference RF --to REF`; `propose_change` gains the kind; the confirm route is unchanged;
- UI: "Promote to canon", and inherited references on cards;
- the image gains git-lfs; the sync sets `GIT_LFS_SKIP_SMUDGE=1`; an LFS push with the deploy key becomes a gate step.

**Criteria outline, PR1-PR10:**
- a promotion exists only as a proposal;
- apply writes bytes whose BLAKE3 equals the reference's at the configured home, in one commit with provenance;
- an existing path holding other bytes is refused;
- an LFS-tracked home gets an LFS pointer, never a raw blob (M: a raw blob committed);
- with no `[references]` home, propose exits 2;
- the key is uncounted: no revision raise, no drift;
- every card targeting the entity inherits it, in its context and on screen;
- `[auto]` holds the kind back (M: the kind in the covered set);
- a lead whose zones do not cover the home gets 403 at confirm;
- a genre test: the core names no kind;
- owner's gate: an LFS push from the hub (pilot A keeps `assets/textures/**/*.png` and `assets/models/art/**/*.glb` in LFS).
