# auto-land (release auto-mode, 0.47.0): a pack started on a terminal, approved and landed by the rule

ADR-0081 replaces the owner's per-task keys on the laptop with one: `spec auto start` asks once, on a terminal, for a pack of tasks and requirement lines. Then the rule approves each task whose plan it covers (`spec auto approve`). It lands each finished one (`spec auto land`): one code commit, its covered task-bound proposals applied, `spec check` clean on the merge, and a `--no-ff` merge into the integration branch, `auto` by default, never pushed. `spec auto next` gives the runner its next act, deterministically: overlapping tasks never run together. `spec auto hold` records the runner's holds.

Spec: `docs/features/auto-land.md`. After RM-0120, beside RM-0121.

Shipped 2026-11-15 in `auto-mode` (plugin 0.47.0): `spec auto start|approve|land|hold|next`, the line binding. Canon: `docs/canon/spec-auto.md`, `docs/canon/spec-auto-land.md`.
