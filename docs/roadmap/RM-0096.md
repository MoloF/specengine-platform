# departments (Phase 7, v5 step 4): the owner's words, department statuses and directions

Shipped 2026-11-11 (`docs/features/departments.md`; ADR-0076, which amends ADR-0073; `docs/canon/workspaces.md`, `docs/canon/directions.md`, `docs/canon/card-flows.md`). The owner's words of 2026-11-10 replace the engine's in the chrome. A department stays a lens, never an entitlement (Q3). Plugin 0.35.0; first-load JS 827.62 kB of 845.

- **The words**, in both catalogs: Department, Task, Subtask, Agent task, Directions. The nav's Tasks reads "Agent tasks". Config keys, CLI, MCP and daemon text are unchanged, with no alias.
- **A flow's `title`**, optional, is served in `list`'s `flows[]`. The Board's tabs, lane heads, Flow row and Subtasks rows show it.
- **Directions.** `[[module]] kinds` is a module chosen by node kind, with no root. The Spec tree lists a direction's nodes flat; a document's Inside groups them under its title; Flow takes rooted modules only. RM-0102 is in the pool.
- **Hand off** picks a department. The daemon serves each department's `disciplines` by the new-card rule.
- **The preset** titles its five flows and ships a commented direction. `read-spec` gains the UI's vocabulary.
- **Rollout.** An older binary refuses `title` and drops every module on `kinds`, so ADR-0073's upgrade rule holds.
