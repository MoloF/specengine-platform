# departments (Phase 7, v5 step 4): the owner's words, department statuses and directions

An ADR `departments`, issued with this slice's spec, amends ADR-0073. The owner's words of 2026-11-10 replace today's: "Project", "Task" for a card, "Subtask" for a child card, "Agent task" for a `T-` task, and "Department" for a workspace lens. A department stays a lens, never an entitlement (Q3). 9-13 pipeline hours.

- **The chrome's words**, in both catalogs: Department, Task, Subtask, Agent task and Directions.
- **Config keys.** They stay as they are: `[[workspace]]` keeps its name, with no `[[department]]` alias. A new top-level key would make an older binary refuse the file.
- **`[[card.flow]] title`**, optional: a flow's display name.
- **Directions.** `[[module]] kinds = [...]` is a module chosen by node kind, with no root, served as `modules[].kinds`.
- **Hand-off** picks a department rather than a discipline word.
- **Presets** give their flows and departments titles.
- **Plugin vocabulary.** The plugin says that the UI's task is a card and its subtask is a child card.
- **Rollout.** A new key follows ADR-0073's rule: an older binary refuses it, so `spec` and the plugin are installed from one commit.
