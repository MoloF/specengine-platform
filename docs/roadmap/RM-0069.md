# screen-fit (Phase 7, step 7d): a drop lands on an empty column, a clean flow takes the width

An empty Board column stands over the free height, so a drop below its heading lands, by CSS alone. When every gap row reads `None` on a fresh read, one line replaces the rows and the canvas takes the width; a failed read keeps `Not read`. Spec: `docs/features/screen-fit.md`. 1 pipeline hour.
