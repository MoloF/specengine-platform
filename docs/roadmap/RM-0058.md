# reuse-overrides (Phase 7, step 16): overrides, variants, usage reads

A using document declares `revises: [DEF#SECTION]` and its part states only the delta; only there is `@rev` pinned, and a row compares it. Key `pack:` plus `follows` into the base gives a variant, a read filter choosing it. Usages are a read, never a copy; rows list definitions with no usage or one. 3-5 pipeline hours.
