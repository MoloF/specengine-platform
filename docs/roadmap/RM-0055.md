# zone-index (Phase 7, step 13): an index-free zone and `status: retired`

A brief is `canon` (owner's decision 9), but canon never reaches Tier 3 (`is_tier3`) and one index line per document cannot carry 10 000 nodes. A zone navigated by tree and search takes no index lines, and `status: retired` moves a brief out of retrieval. Issues `zone-index`, which amends ADR-0030 and ADR-0022. 2-3 pipeline hours.
