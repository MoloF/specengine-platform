# english-polish: the UI's English grammar slips, fixed with their tests

The sweep (RM-0090) kept English byte-equal to the strings it replaced (R11), slips included. A plural group whose `_one` form repeats `_other` reads wrong at 1: "1 links not shown" (`tree.links.omitted`), "1 cards not shown." (`board.view.omitted`), "1 tokens" (`tree.binding.tokens`), "1 holders" (`graph.holders`, `tree.node.holders`), "holds 1 more boxes" (`graph.details.moreText`). Fix each `_one` in `ui/src/i18n/en.ts`, sweep the other plural groups for the same slip, and update every test that expects the old English; Russian keeps its forms. A test reads each fixed form at 1, so restoring a slip turns it red. UI only, no daemon change; `docs/canon/ui-languages.md` "Known limits" drops the line. Under an hour. Not drafted.
