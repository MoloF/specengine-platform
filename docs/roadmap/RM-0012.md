# review-form: the owner's MCP staging form `review_proposal`

Deferred from Phase 2 (08 s2). In the session the owner picks an option, the working answer or a reject in an elicitation form; the server stages that answer through the CLI library's `stage`, as the daemon does, and `spec approve|reject PR` on a terminal confirms it (ADR-0035).
