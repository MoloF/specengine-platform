# impact (7b): the blast radius of a node, a symbol or a revision

What a change reaches, for a node, a code symbol or the code changed since a revision: the nodes, each bound symbol with its `sync`, the tests, the open tasks (ADR-0046). Executed by two slices (split 2026-10-21):
- 7b-1 `docs/features/impact.md`, shipped 2026-10-21 (`docs/canon/spec-impact.md`): `spec impact REF | --symbol QPATH`, MCP `get_impact {id?, symbol?, depth?}`, the open tasks in the radius, the `implement` skill naming it, plugin 0.15.0;
- 7b-2 `docs/features/impact-since.md`, open: `--since REV`, `delta.symbols` in `spec verify --changed --json`, `get_impact`'s `since`, plugin 0.16.0.
