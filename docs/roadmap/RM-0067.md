# proposal-rehearsal (Phase 7, step 7b): a dry run, no false `ref-dangling`, one sitting of approvals

Learning stops spending the owner's attention. `propose_change {dry_run}` and `spec propose update|create --dry-run` give every refusal and finding of the real call and store nothing. A `ref-dangling` on an ID a live create or amendment holds is left out, with a note naming the holder. `spec approve --open` walks the open applying proposals, oldest first, one `[y/N]` and one commit each; one consent over a set is out and stays with the owner (ADR-0038). Built on the shipped queue, so it waits on no open item. Spec: `docs/features/proposal-rehearsal.md`. 1.5-2 pipeline hours.
