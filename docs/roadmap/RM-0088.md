# plain-questions (Phase 7, v4 step 6): questions in plain language, collisions as pairs

Today's questions are walls of IDs, file paths and code names. `ask_question` gains a one-line gist, why it matters, and 2-3 options with their consequences, mirroring a discrepancy's options and recommendation. The AI's recommendation is labelled as the AI's. The UI shows titles rather than IDs and folds the IDs, paths and spans under a technical detail, and the MCP descriptions ask for plain words. The engine structures and folds; it never rewrites an agent's text, since there is no LLM inside. 6-10 pipeline hours.

Collisions show as pairs, "what conflicts with what", side by side under their titles. They build on RM-0060 `collision-pass` (`report_discrepancy`, `contradicts`) and RM-0059 `intake-similar`, and this slice's spec settles the order between them.
