# flow-directions (Phase 7, v5 pool): Flow drawn through a kind direction

RM-0096 `departments` serves `[[module]] kinds`, a direction with no root, and Flow takes rooted modules only: it draws from a root, and a kind is no root (`docs/features/departments.md` D6, ADR-0076 "Cost"). This item would let Flow draw a direction: the drawing read cut to the direction's kinds, as `in_flow` cuts it (`docs/canon/spec-flow-cuts.md`), from Top or a module's root. Taken only if the pipeline trial or the owner asks for it. Unestimated.
