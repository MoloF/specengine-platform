# journeys (Phase 7, v5, optional): one act hands a task to several departments

This is optional and waits for the pipeline trial (Q9). It is the owner's step 4: a task is split to departments, each deciding on its side. 6-9 pipeline hours.

- **Config.** `[[card.journey]]` names a node kind and its steps, each `{department, after = [...]}`.
- **Starting a journey** on a task makes one subtask per step, each with its reviewer: RM-0085's hand-off, done several times in one act.
- **`after`** is a soft dependency, shown as "waiting on" and as in and out counts. It never refuses a move (ADR-0012, ADR-0074).
- **ADR.** A new top-level key needs an ADR and ADR-0073's rollout rule.
