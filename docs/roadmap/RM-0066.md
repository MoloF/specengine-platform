# trace-truth (Phase 7, step 7a): a nested edit marks, counts stop at containers, a card read shows its mark

A change anywhere in a target's text marks its cards: a `within_hash` over the node and its nested ID sections is frozen beside `norm_hash`, which stays as it is, and a mark stops at the file. A node holding live documents with no card of its own is counted nowhere, its row still `no card`. `get_card` is `spec card show --marks`. From the trial of 2026-10-31: on the layout ADR-0026 prescribes, "a changed node marks its cards" was untrue. Spec: `docs/features/trace-truth.md`. 2-2.5 pipeline hours.
