# hub-mcp (Phase 7, step 11): `/mcp` with a session, identity to author, hub tools

MCP over the network: GET and SSE with a session, the proxy's identity becoming the author, a hub tool set and its own instructions (the stdio text has 8 B left). Calls run inside the per-project turn. Every hub tool leaves `git status` empty (08 s3 AC-3). Whether a writer's client attaches a remote MCP with a per-person credential is unmeasured, the largest unknown in the plan, and is checked by hand first. 5-9 pipeline hours.

- **A duty from `hub-confirm`.** A `/mcp` credential yields the same `Remote-User` as a person's session, and the daemon cannot tell them apart, so only the proxy can keep it off every other path, the confirm routes first. This step says how that credential is scoped, and RM-0064's rules carry it.
