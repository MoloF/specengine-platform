# local-landing (Phase 7, v4 step 0): a link from another site opens the local daemon's page

Found 2026-11-08 during the owner's review of Flow. A link to the local daemon from another site, such as a chat or a mail, lands on a raw JSON 403, because the local fence refuses `Sec-Fetch-Site: cross-site`. The hub admits such a top-level navigation to `/` (`docs/canon/hub.md` "Fence"), and the local daemon now admits it the same way: `GET /` with `Sec-Fetch-Mode: navigate` and `Sec-Fetch-Dest: document`, with `Host` and `Origin` still judged first. Both fences use one predicate. This is a canon change, with no ADR: the hub's landing came in through the canon too. The step needs no input from the owner and may ride with 1a. Spec: `docs/features/local-landing.md`. 0.5-1 pipeline hours.
