# local-landing (Phase 7, v4 step 0): a link from another site opens the local daemon's page

Shipped 2026-11-09 (`docs/features/local-landing.md`; `docs/canon/serve-ui.md` "Rules", `crates/specengine-http/README.md` "Fence"), a canon change with no ADR: the hub's landing came in through the canon too.

Found 2026-11-08 during the owner's review of Flow: a link to the local daemon from another site, such as a chat or a mail, landed on a raw JSON 403, because the local fence refused `Sec-Fetch-Site: cross-site`. The local daemon now admits a hub's landing the same way: `GET /` with `Sec-Fetch-Mode: navigate` and `Sec-Fetch-Dest: document`, `Host` and `Origin` still judged first. Both fences call one predicate; every other request from another site is refused as before.
