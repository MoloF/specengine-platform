# flow-read (Phase 7, step 2): `spec flow`, `get_flow`, lifted edges and gap rows

`spec flow ROOT --depth` and MCP `get_flow`: the walk over `follows`, byte-identical across file orders. `--depth` lifts inner edges across `parent:` groups with counts, computed in the read, so the UI computes nothing. Gap rows name IDs, in the form of ADR-0047 (computed per read, stopping nothing): no start, unreachable step, no way to an end, trap cycle, unjoined `parallel`, unmarked cycle, unused definition. Treating every cycle as a gap must fail on a fixture with a cycle meant to run forever. To settle here: how such a cycle is declared, since ADR-0055 fixes three kinds and an `endless` marker is no fourth. 3-5 pipeline hours.
