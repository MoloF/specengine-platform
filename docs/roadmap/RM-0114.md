# board-subtasks (patch 0.46.1): the Board shows all cards, tasks only or subtasks only

The owner reported this on 2026-11-14 while using the hosted hub (0.46.0, his game project). He wrote in Russian; paraphrased: the Board has no filter showing only top-level tasks, without their subtasks, and none for the opposite, every subtask, as Jira has.

A split (`docs/canon/card-split.md`) gives one parent and a subtask per department, so a board mixes both levels. A "Show" select beside Lanes picks All cards, Tasks only or Subtasks only, per project in `localStorage`. With Parent lanes, Subtasks only groups the subtasks by their parent.

The list read already serves each card's `parent`, so the slice is UI-only. Spec: `docs/features/board-subtasks.md`, no ADR. It ships in the patch release 0.46.1 with the other items RM-0114 to RM-0119: a hub runs tagged images, so the plugin's version goes to 0.46.1.

Shipped 2026-11-14 in the 0.46.1 patch: Show (All tasks, Tasks only, Subtasks only, ADR-0076's word), `specengine.board.level.<p>`, a subtask's parent line. Canon: `docs/canon/board-lanes.md`.
