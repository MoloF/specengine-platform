# hub-department (Phase 7, v5 step 13): a hub's per-login default department

On a hub, a login opens on a default department named in the workspace table. This is a presentation-only default, never an entitlement (Q6). `[team]` and its roles stay what they are, the acts' entitlements (ADR-0060), and are untouched. "View as" beside "Acting as" must not read as an identity. It may issue `hub-workspace`, which supplements ADR-0060.
