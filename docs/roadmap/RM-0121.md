# hub-auto (release auto-mode, 0.47.0): a hub applies its sole owner's covered proposals

On the hub each of the owner's agent's proposals takes a click and a second factor. ADR-0082, narrowing ADR-0061, lets the hub's code apply an `update` or `create` raised over `/mcp` by the sole `owner` login when the committed rule covers it. It runs as its own command in that login's line after the propose answers, commits under that login with `Delegated-by:`, and is read per command from the checkout's `HEAD`; the operator's stop file and a second `[team]` login switch it off with no restart. `tests/door.rs` admits one door file, http `src/auto.rs`.

Spec: `docs/features/hub-auto.md`; canon `docs/canon/hub-auto.md`, the operator's part in `docs/canon/hub-ops.md` "Auto". After RM-0120, beside RM-0122.

Shipped 2026-11-15 in `auto-mode` (plugin 0.47.0): `HubSeam::proposed`, http `src/auto.rs`, `auto_apply`. Canon: `docs/canon/hub-auto.md`. Owed: HA9 (gate G3), the owner's on the live hub after the upgrade.
