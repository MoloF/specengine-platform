# tree-bindings: opt-in binding counters in `spec tree`, `get_tree` and the daemon's tree

Each tree line would count its node's own bindings by class, opt-in (`spec tree --bindings`, `get_tree` `with`, `tree?with=bindings`). By default every tree load would judge the whole tree (`docs/canon/code-reads.md` "Known limits"). This was moved out of RM-0011 on 2026-10-21 (Q-B): the UI's tree badges read Health's row 6 instead (`docs/features/ui-tree-drift.md`). It waits until an agent needs the counters. A returned key is a plugin MINOR (`docs/canon/plugin-files.md`). Not drafted.
