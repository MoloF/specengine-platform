# auto-feed (release auto-mode, 0.47.0): what happened, newest change first, and what needs the owner

The owner follows a night's run and reads it in the morning. `spec feed` and `GET .../feed` (local and hub alike) list the queue's events in order: runs with their outcome and summary, delegated applies and lands, holds with their reasons. `--needs-me` lists what waits for him: held items, open proposals, failed runs, the `gate.observed` writes and done tasks not landed.

The UI adds Activity, a feed view marking what is new since each viewer's last visit, updated live from the events stream. It also adds a Tasks sort by last change, and "Applied by rule" on a decided proposal.

Spec: `docs/features/auto-feed.md`. Beside RM-0121 to RM-0123 once RM-0120's event names are fixed.

Shipped 2026-11-15 in `auto-mode` (plugin 0.47.0): `spec feed`, the route, Activity, the Tasks sort. Canon: `docs/canon/spec-feed.md`. Owed: FD8, the owner's overnight run (gate G4).
