# ADR-0033

**Decision.** Web UI work starts now, before `spec serve`: `ui/` is a standalone pnpm project (TypeScript, Vite, ESLint, Vitest) that reads and decides only through one client interface; until the daemon exists its only implementation is a typed mock, and its types are provisional hand-written ones that types generated from Rust replace (the generated win). Dependencies are exactly the owner's allowlist, 15 packages at exact versions; a new package or any version change is an owner decision.

**Why.** The owner wants the review screens shaped while Phases 1–2 run. One seam turns the switch to the daemon into a bootstrap change, not a rewrite.

**Cost.** Every hand-written shape is a guess the daemon may overrule: rework at the switch. A JS toolchain and a lockfile on the laptop; security patches wait for the owner. Time taken against 08 §5's scope-creep risk. Until the owner updates `.claude/`, each slice spec lists its exceptions to the `ui-developer` prompt, which assumes Phase 4.
