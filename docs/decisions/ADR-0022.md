# ADR-0022

**Decision.** `docs/canon/documentation-system.md` applies in full: classes, tiers, budgets, front-matter, promotion rule, generated index, §11 checks — here (`cargo xtask docs check`) and in every project under SpecEngine.

**Why.** The W = O(1) invariant holds only under enforcement.

**Cost.** Every documentation change passes the check; caps are never raised.
