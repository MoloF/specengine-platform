# ADR-0002

**Decision.** R/A/Q/DEC/AC/TERM — one file per record; a node document (mechanic, feature) is one file, its rules are addressed as `{#ID}` sections.

**Why.** Atomic diffs and conflict-free merges; a human reads a node document whole.

**Cost.** Thousands of small files after importing a corpus; the hash is computed per section.
