# ADR-0028

**Decision.** In the generated index, a Tier 3 document's line carries only its id link and its status: `- [<label>](<link>) <status>`. Live lines keep id, title, scope and status: the convention's §9 (ADR-0022) is unchanged for them. Tier 3 is chosen by status, as before; one format for every project, no config key (ADR-0008).

**Why.** Tier 3 is excluded from default retrieval and reachable by id (§3), yet title and scope were ~60 % of the archive's bytes in the index, and every shipped spec added ~196 B while the caps never move.

**Cost.** Archive titles leave the index: an agent finds a Tier 3 document by its slug, a citation or `spec search --archive`. Growth stays O(n): the durable fix (roadmap Q-8 sharding, or a terser live line) is due before Phase 2 and before the first pilot registers `spec export index`. Tier 3 stays in the index; whether it leaves is decided with Q-8.
