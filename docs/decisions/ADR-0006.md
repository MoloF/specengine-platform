# ADR-0006

**Decision.** The `PreToolUse` hook is a `command` hook and returns exit 2 when SpecEngine is unavailable.

**Why.** An HTTP hook lets the edit through on failure — an open gate.

**Cost.** Without a running daemon an agent cannot edit code in controlled zones (`observe` mode lifts this).
