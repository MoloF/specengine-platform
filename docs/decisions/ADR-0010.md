# ADR-0010

**Decision.** `// @implements ID` (and `@verifies`, `@configures`, `@assumes`) in `.rs` and `.ron`.

**Why.** Zero dependencies in the consumer project; works in RON too.

**Cost.** Binding to an item relies on comment proximity, not an attribute.
