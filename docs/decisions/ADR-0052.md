# ADR-0052

**Decision.** A plan item, placed or in the pool, is one `spec`-class Markdown file in the project's git whose `id:` has the prefix `[roadmap]` names; its release, priority, estimate and `depends_on` chain are front-matter, changed as any spec file is. Tasks stay in the queue and execute items by targeting them. Position (done, in progress, current release, order, time left) is computed per read, never stored; a committed view of it is `generated`, from git alone. The chain orders work, never gates it (ADR-0012).

**Why.** The plan survives deleting the database and shows in diffs (ADR-0001, ADR-0003); a file per item merges cleanly and is cited like any node (ADR-0026).

**Cost.** A file and an index line per item (a shard, ADR-0030); task progress shows only beside its queue; 08 §4.1's roadmap and milestone rows reverse; this repository's closed `spec` class admits the item keys.
