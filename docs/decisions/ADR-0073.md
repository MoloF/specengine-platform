# ADR-0073

**Decision.** Accepted by the orchestrator as a working answer, the owner's review open. A workspace is a lens: its nav's sections in order, a landing, the card flows its Board shows, a default module. A module is a root document and its subtree. Both are `specengine.toml` tables read apart, as `[flow]`, `[card]` and `[team]` are; a bad one serves the implicit workspace, every section but Tasks, with a note. Every section keeps its route. A viewer's choice is local (`localStorage`); a hub login's default is RM-0089's, and `[team]` stays the acts' entitlements (ADR-0060). The gamedev preset is a file outside the crates (ADR-0008).

**Why.** The owner wants each trade to see its own pages. A lens decides nothing, so it is no control point (ADR-0012), and the core names no trade.

**Cost.** Older binaries refuse the tables, so a hub-served project adds them only after its hub upgrades. A module names one root: a kind selector needs a corpus read. A choice does not follow its viewer to another browser.
