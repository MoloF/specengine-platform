# ADR-0068

**Decision.** Accepted by the orchestrator in the owner's absence; awaiting the owner's confirmation, which 08's row asks for (`accepted` is the convention's only status for it). Supplements ADR-0034, ADR-0059 and ADR-0067. A hub's account acts are `scripts/deploy/admin/hub-admin`, POSIX `sh` driving the door's own CLI, run by `docker compose run --rm admin` in a one-shot service with no network, port or log, refused without a terminal: root is the host's shell. No crate holds account code; SpecEngine adds only the read `spec team`. The door re-reads a person on every request; a hub's streams end after a maximum life (RM-0075).

**Why.** The owner asked for a root CLI on the server that only a container reaches. A `spec admin` would put accounts in SpecEngine and the daemon's binary, against ADR-0034 and ADR-0059, with hash crates and the door's SQLite.

**Cost.** Shell over the door's files and CLI flags, from memory until checked on the pinned image; a `[team]` row is still a reviewed commit; a reset ends no live session.
