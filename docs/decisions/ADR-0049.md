# ADR-0049

**Decision.** rust-analyzer (`ra_ap_*`) is linked only into the executable `specengine-ra`. Only `spec resolve` spawns it: own process group, a budget, a versioned JSON request on stdin, JSON lines on stdout; no read, MCP tool, daemon, hook, `check` or `verify` does. Its answer, a moniker or a reason per layer A item, is index data in the data directory for the tree it saw, stale after any change: never a binding, `spec.lock` key, verdict or finding; absent or failed, it changes nothing else. It runs no project build script or proc macro; running them needs the owner's start on a terminal and a scratch copy (ADR-0044).

**Why.** A cold load costs seconds to a minute, gigabytes, rustc >= 1.98 and an API without guarantees; the marker stays the identity (ADR-0020); nothing blocks (ADR-0012).

**Cost.** A third, optional binary from the same commit, in place of 04's `rust-analyzer scip` subprocess; any edit leaves its rows stale until the next run; ambiguous bindings stay `cannot_verify`. Adds to ADR-0020 beside ADR-0048 (layer B); supersedes nothing.
