# ADR-0088

**Decision.** A reference, a file or a link, is a queue row under a card, a node or a proposal, authored and deleted as a comment (ADR-0087). A file's bytes live in a BLAKE3-named store in the data directory, a hub's own volume: never a repository, a dump or an off-host copy, narrowing ADR-0071. One binary route streams an upload outside the turn; its type is its sniffed bytes, from a list a project may narrow; caps bound it; files are served sandboxed. Images reach agents as MCP image content up to 1 568 px and 1 MiB, else as a browser-made copy; audio, video, models and PDF need "what matters here". `evidence` stays. Amends `architecture.md#ui`: the UI uploads.

**Why.** People's material belongs beside the work and its agent, never passing for truth or swelling the repository.

**Cost.** Files die with the hub's host: the owner's accepted risk (2026-11-22). Queue schema 16, dump format 9 and a volume: every binary and the hub upgrade together, a dump first. Up to 10 GiB of disk a project.
