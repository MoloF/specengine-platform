# ADR-0048

**Decision.** A layer B fact, one only a build or run of the project knows (a framework's registration dump), reaches SpecEngine only as a file the project writes and names in `[code]`; SpecEngine never patches, builds or runs the project to get it. The file's bytes key the index. Its facts annotate layer A symbols: never a symbol, binding, `spec.lock` key, verify verdict or check finding; missing, unreadable or stale, it is a note, never an exit (ADR-0012). On what is registered where, it outranks the syntactic detector, both shown. Its readers live in `specengine-code`; core and store hold a path and an opaque format name (ADR-0008). Layer C is not decided here.

**Why.** A dump is an instrumented build and run: minutes, gigabytes, project code (ADR-0013, ADR-0044); a read stays one input, one result; the marker stays the identity (ADR-0020).

**Cost.** The file goes stale between the project's runs: SpecEngine shows disagreement counts, not age. Each framework minor may need a new format name and reader. Adds to ADR-0020; supersedes nothing.
