# ADR-0020

**Decision.** The marker provides the identity of a link; rust-analyzer as a library is added in Phase 3.

**Why.** A cold rust-analyzer start costs minutes and gigabytes; the MVP does not need it.

**Cost.** Ambiguous symbol paths yield `cannot_verify` in the MVP.
