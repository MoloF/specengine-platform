# ADR-0053

**Decision.** `spec lock diff REF [--json]` and `GET /api/projects/:p/lock-diff?ref=<REF>` show, for each binding the lock holds for REF's holders, the node's text at the entry's `commit` and the code at its `file_blob`, both against the working tree, as hunks git makes (`cat-file`, then `diff --no-index` over scratch copies in the data directory). Computed per read, never stored; a gone object leaves that side empty with a note; nothing depends on the result; no MCP tool.

**Why.** A drifted row says that a side moved, not how; the owner decides a drift item or an accept without running git by hand. Git holds both old sides and `spec review` makes hunks this way already: no diff library (`stack.md` "Not taken"), no diffing in the UI (`architecture.md#ui`).

**Cost.** The reads' git list gains `diff --no-index`, for this read only; old objects must stay reachable (a squash or gc empties a side); a git process or two per side, on demand, in the daemon's project turn. Adds to ADR-0046; supersedes nothing.
