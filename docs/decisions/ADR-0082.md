# ADR-0082

**Decision.** On a hub whose `[team]` names one login, role `owner`, and whose committed `[auto]` takes a hub, the hub's code applies each `update` or `create` that login raises over `/mcp` when the predicate covers it: covered zones, no excluded zone or kind, no config target, a clean apply, no findings, no stage, under the day's cap, no stop file. It runs as its own turn after the propose answers: one commit under that login, `Delegated-by:` trailer. Everything else waits for a click. Narrows ADR-0061.

**Why.** The owner's agent works on his hub alone; a click plus a second factor per proposal judges nothing he has not already ruled.

**Cost.** The `/mcp` secret applies past the step-up within the cover; a delegated commit reaches the remote with the next sync, no integration branch; `tests/door.rs` admits one more door file.
