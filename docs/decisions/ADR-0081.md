# ADR-0081

**Decision.** A project may commit `[auto]` in `specengine.toml`. One terminal `[y/N]` starts a pack of tasks; then SpecEngine's code alone, a predicate over the rule frozen at start and at `HEAD`, the queue and git, approves each pack task and lands each finished one: a code commit, its covered task-bound `update` and `create` applied, `spec check` clean, a `--no-ff` merge into the rule's branch, never pushed. Each act is an event `by: "rule"` and a `Delegated-by:` trailer; a runner outside `spec` drives the agents. A second `[team]` login, the stop file or removing the table switch it off. Amends ADR-0012, ADR-0035, ADR-0038.

**Why.** The owner works alone; his per-task and per-proposal keys judge nothing. Agents still only report, so no tool takes a choice from an agent.

**Cost.** Working answers become merged code overnight; one key consents to a set; any local process may call `spec auto approve` or `land`, passing only the predicate (ADR-0034).
