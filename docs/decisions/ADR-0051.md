# ADR-0051

**Decision.** `spec health`'s rows 4-5, and its route's, take code from the code index the call refreshes, as `spec refs` does: open the index, `refresh_code`, `require_complete`, `code_refs()`; never a walk of their own. Row 5 binds a node by `spec unmapped`'s predicate: an ID naming nodes, placed on an item, a module or a RON path; a `cannot_verify` marker binds nothing. No `[code]`: both rows not measured; a refresh that fails makes them `cannot`, row 3 and the exit as they were.

**Why.** Health, `refs` and `unmapped` must give one answer about the same marker; a second reader would revive the walk 6a-2 left only as a test oracle, and parse the whole tree per Health entry.

**Cost.** Amends ADR-0047: Health writes the code index too (still only the data directory) and its first call builds it in the project's turn; a broken item's marker leaves its node unbound. Adds to ADR-0046; supersedes nothing.
