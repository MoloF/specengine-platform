# ADR-0075

**Decision.** Supplements ADR-0056. A card links `T-` tasks as a list of IDs on its own row, behind queue schema step 10, and nowhere else. No gate, card move or accept, and no task's approve, claim or complete, reads the link. A task's state is read and shown per request and proves nothing: it refuses no card and moves none. The link is local: a hub keeps the IDs as written, reads no task and shows them without state.

**Why.** The owner wants an agent's task shown inside its card with the `T-` model and the gate kept (decision 3). A link that decided anything would reach the gate (ADR-0012), and a hub runs no `T-` flow (Q2).

**Cost.** A schema step: older builds refuse the queue, the hook gives no verdict until `spec` and the plugin reinstall from one commit, and older importers refuse backup format 4. ADR-0056's link proving code work stays unbuilt. On a hub one `T-` ID may name a different task on each terminal.
