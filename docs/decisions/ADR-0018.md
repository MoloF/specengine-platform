# ADR-0018

**Decision.** `@implements ID@rev` records the spec revision in code; `spec.lock` keeps AST hashes of the verified state.

**Why.** A revision bump is visible in the code diff as a review record (tracey's discipline).

**Cost.** Two places of truth about a binding, tied together by a check.
