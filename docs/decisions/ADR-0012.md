# ADR-0012

**Decision.** No blocking flags and no `blocked` status; several proposals per node; an agent works on a working answer with `@assumes`. Only a task approved by the owner goes into development.

**Why.** The owner works on several documents at once and processes the queue as it comes.

**Cost.** Decisions that differ from the working answer spawn follow-up tasks.
