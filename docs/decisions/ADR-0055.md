# ADR-0055

**Decision.** Three domain-free types join the shared table: `follows` (on the later step; an item is a plain ID or `{to, when, kind}`, `kind` one of `alternative`, `parallel`, `repeat`; cycles allowed), `uses` (reuse by reference) and `supplies` (what produces or feeds what, on the producer). `depends_on` keeps its meaning and its `depends-cycle` warning. `kind` and `when` count in `norm_hash` under `specengine-norm/v1`: such an item nulled its document until now, so no hash changes and nothing is re-locked. Impact follows `uses` and `supplies`, never `follows`.

**Why.** Games loop, and a loop in `depends_on` is a defect. Sequence, reuse and supply are different meanings, and ADR-0031 forbids a project's own type. A changed branch condition is a changed meaning.

**Cost.** Three more types in every walk, table and test; a label on `Reference` and one index format raise; a pack adding a consumer edits the producer or declares `uses`; a step edit reaches later steps only on request (`spec graph --impact --type follows`).
