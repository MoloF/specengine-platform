# ADR-0036

**Decision.** Spec prose renders as markdown through `react-markdown` 10.1.0 and `remark-gfm` 4.0.1, imported only in `ui/src/markdown/`: React elements, never an HTML string; raw HTML stays text (no `rehype-raw`, no `allowDangerousHtml`); a link is an anchor only where the daemon's links read resolved it. The source stays one toggle away. Amends ADR-0033: its allowlist grows from 15 to 17 packages; the rest holds.

**Why.** The owner reads documents, not markup (07 s3, "markdown + preview"). Two widely used MIT packages beat a hand-written parser reading headings unlike core and an HTML string behind a sanitizer, an HTML sink.

**Cost.** About 95 lockfile packages, mostly one maintainer's; security patches wait for the owner. A second markdown reading beside core's `markdown.rs`: footnotes and bare-URL autolinks added, no `{#ID}`, rare headings read differently. One harmless `innerHTML` in the bundle (an entity decoder). Shipped criteria asking for verbatim text change.
