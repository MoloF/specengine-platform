# ADR-0029

**Decision.** ADR-0023 is amended. One pipeline, `/feature`, every role on Opus 5.5 set in its front-matter: `/feature-saving`, the `*-saving` twins and `scripts/sync-saving-agents.sh` are dropped. The role table: `spec-writer` also writes `specengine.toml` and `.spec-debt.toml`; `rust-developer` also `.githooks/`, `.github/workflows/`, `scripts/`, `.cargo/`; `xtask/src` and `xtask/tests` leave the developer's and the test-engineer's areas with `xtask/`, which the switch deletes. `.claude/**` is the owner's: a role prepares its text in the spec, the owner applies it.

**Why.** The documentation gate moves into the product (ADR-0013, ADR-0022): `spec check`, configured by the root `specengine.toml`, run by the pre-commit hook and CI. The config, the debt baseline, the hook and CI need owners. The twins copy every role prompt and need a generator and its check in the hook and CI.

**Cost.** No fallback role set when the main model's limits run out: switching models means editing the roles' front-matter by hand. The developer can edit the hook and CI that judge its work; the spec-writer could add expiring debt instead of fixing errors. The reviewer watches both. Every `.claude/**` change waits for the owner.
