# ADR-0038

**Decision.** Supplements ADR-0035: `spec round answer FILE` on a terminal stages each answer the file returns, then confirms each with that item's own `spec approve|reject` question and `[y/N]`: one key per answer, never one for a round; any other key keeps the stage. A stdin that is no terminal exits 2 before anything is read, so agents never stage through it. `spec approve|reject` stays the other confirming path; the UI only stages.

**Why.** A round returns many answers at once. One consent for all (06 s5.3) would let a reflex `y` decide items the owner never saw; a stage plus its own question per answer keeps one confirmation per decision.

**Cost.** A long round asks many questions, each record shown whole (`--limit`); a second command writes stages (`stage.rs`, `decision-staging.md` "Rule" change); a line planted in a pasted reply is staged before it is read (column-0 answers, indented agent text, refused characters, caps, step 7); a faked terminal still passes.
