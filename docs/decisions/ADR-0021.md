# ADR-0021

**Decision.** A symbol hash is built by a normalizing tree-sitter walk (spec 05 §5.2); `syn` 3 is compared in the Phase 0 spike.

**Why.** Tolerant to parse errors, one engine for `.rs`; follows from ADR-0020.

**Cost.** tree-sitter traps (ERROR is extra, rustfmt commas) are closed by tests.
