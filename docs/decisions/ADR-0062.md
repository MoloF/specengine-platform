# ADR-0062

**Decision.** Amends ADR-0005's commit and the generated rule: every apply, on a terminal and on a hub, commits beside its spec file the `index = true` entry's changed outputs, rendered by SpecEngine from the committed tree (`HEAD` plus the apply's paths), never the disk walk; still one commit. A project's generator command never runs (ADR-0013); with no `index = true` entry nothing changes. The target, `spec.lock`, `specengine.toml`, `.spec-debt.toml`, a path outside the walk or a document not `generated` is never an output. An output never refuses an apply (ADR-0012): a gap, or one git will not stage, commits the target alone with a warning.

**Why.** A create or a status change left `index-drift`, an error, so an `enforce` hook stopped the next Markdown commit, and a hub's pushed commit would stop everyone's. The committed tree is the one a staged hook judges.

**Cost.** Applies touch generated files, so two branches' applies conflict on the index. Completion accepts the outputs the parent's config names, their bytes unjudged. Each apply reads `HEAD`'s tree under the root; a partial clone missing blobs gets no index.
