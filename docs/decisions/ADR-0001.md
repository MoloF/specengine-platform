# ADR-0001

**Decision.** Specs and bindings live in the project repository (Markdown + YAML, `spec.lock`); SQLite is a rebuildable index and the operational queue.

**Why.** A spec travels on a branch with the code and agents' worktrees, and is reviewed in the diff; no second document store is created.

**Cost.** An indexer and file watching are needed; the queue in the database must be backed up (ADR-0003).
