# ADR-0059

**Decision.** Supplements ADR-0034 and ADR-0057: a hub takes a person from one fixed header, `Remote-User`, set by the proxy, judged in the fence on every request. No account, token, key or session exists inside SpecEngine. None, two or a malformed one is a 403 on every route. The login is recorded verbatim as the actor of five plain card writes; a body's `as` may only restate it. Every login reads every served project. What needs consent stays local until `hub-confirm`. No agent runs on that host.

**Why.** Local, a typed name is a convention; a hub needs a person without code that owns one. The proxy owns login and recovery; a shared secret with it would be the token ADR-0034 forbids.

**Cost.** The daemon cannot tell the proxy's header from any process reaching its socket, so only RM-0064's deployment and an agent-free host stand behind it, and a test pins that trust. Every login reads everything. `by = ["lead"]` refuses everyone on a hub, since `as` is a login. `Decided-by` and a person in `Author` wait for RM-0050.
