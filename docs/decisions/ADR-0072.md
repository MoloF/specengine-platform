# ADR-0072

**Decision.** Supersedes ADR-0014, narrows ADR-0024 by one file, amends decision 10 of 2026-10-30. The UI's own words are English or Russian, each viewer's choice, kept in the browser; with none, a Russian browser starts in Russian. Spec content shows as written; the daemon's, CLI's and MCP's text stays English and verbatim. Each string is a key of one catalog: English is the key source, Russian is typed against it in `ui/src/i18n/ru.ts`, the only Russian file. Keys, comments, tests and docs stay English. The library is i18next with react-i18next at exact pins, imported only in `ui/src/i18n/`.

**Why.** The owner's writers work in Russian. He asked for a good, reliable library (Q2): MIT, the most used React stack, plurals by `Intl.PluralRules`, typed keys.

**Cost.** Two packages and both catalogs load with every page. A screen mixes languages until its slice converts it; a Russian screen shows English refusals. The owner reviews Russian he did not write. A third language needs a new decision.
