# ADR-0085

**Decision.** SpecEngine's user guide is canon of this repository: `docs/guide/<topic>.md`, in English, each rule a `{#ID}` section. Every build of `spec`, the daemon and the MCP server embeds it and serves it read-only, through `spec guide`, a tool, a route and a Documents shelf.

It never enters a project:
- no project file, index row, check, map or ID space holds it;
- `spec init` copies nothing;
- nothing loads it into a context unasked.

A project cites it as `guide:<topic>#<ID>`. ADR-0001, ADR-0015, ADR-0022, ADR-0024 and ADR-0027 stand.

**Why.** A project reads the guide of the build it runs. A copy would freeze an old version, be a spec file written outside `apply_proposal` (ADR-0004), and enter the project's check and IDs.

**Cost.** Only a workspace build carries it; a project cannot amend it; its freshness rests on a date warning here; every session sees one more tool.
