# ADR-0087

**Decision.** A comment is a queue row under a card, a node or a proposal: never a file, a commit or `queue.md`, deciding nothing. Its author is a queue author's: the login on a hub, the typed name locally, `agent` over stdio. Only its author edits it, each edit a kept version. On a hub its author's login or a `[team]` `owner` deletes it, on a terminal anyone after `[y/N]`; no MCP tool deletes, and a delete erases every version's text. An item may name its `comment_id` (ADR-0077's pattern), deciding nothing. A card's context carries its newest comments outside the bundle, marked as data. This amends `architecture.md#ui`: the UI also writes comments and the items raised from them.

**Why.** Talk about work should sit beside it and reach its agent, yet never pass for a decision: it becomes one only through an item a person confirms.

**Cost.** Queue schema 15 and dump format 8: every binary and the hub upgrade together, a dump first. Any login's text reaches agents. Deleted text survives in older dumps. Mentions name unverified logins.
