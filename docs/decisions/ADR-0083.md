# ADR-0083

**Decision.** This extends ADR-0069 to a write's introduced findings: those of a propose, or of a deciding kind's approve, a confirm's read and write among them. The check takes each file as the call's walk indexed it, trusting its stat key, instead of reading and hashing every file. From disk it reads only:
- the changed file;
- the config, the baseline and the template;
- the files whose findings it recomputes;
- the index outputs it renders again.

If a file it reads differs from its row, the check runs whole from disk and doubts the index. The digest and the rows come from one read transaction. Findings are memoised per process, inside the project's turn.

**Why.** At 1 841 documents, reading and parsing every file twice was most of a confirm. The walk already decides what every read sees.

**Cost.** ADR-0069's limits now reach a write's findings, though not the bytes it writes: a same-size edit that moves neither mtime nor ctime, a clock set forward, a network file system's attribute cache, a stale local writer.
