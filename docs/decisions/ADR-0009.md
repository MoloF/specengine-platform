# ADR-0009

**Decision.** All IDs are Latin; legacy IDs of an imported corpus are `aliases`, the prefix mapping lives in `specengine.toml`; mixed scripts are forbidden.

**Why.** Homoglyphs (Cyrillic vs Latin look-alikes) make references invisible to grep and checks.

**Cost.** Reference migration in imported corpora; git history is read through aliases.
