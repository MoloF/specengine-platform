# ADR-0003

**Decision.** Database in `~/Library/Application Support/specengine/`; `docs/generated/queue.md` in git; a JSONL dump via `spec export --state` to a backup directory.

**Why.** WAL does not work on synced file systems; queue noise stays out of diffs.

**Cost.** Backing up the queue is a separate command, not git history.
