# ADR-0037

**Decision.** Supplements ADR-0006 until `spec serve`: the gate is a `command` `PreToolUse` hook running `spec gate`, which reads the config, git and the queue itself. No verdict (`spec` missing or failing; config, git, queue or input unreadable; a deadline) is closed: exit 2. A gated write opens only for an `in_progress` task claimed in the file's worktree, on its branch, of the same git common dir. No `[gate]` table: off. It never answers `allow` and reads no proposal, `stale` or check (ADR-0012). Threat model: a cooperative agent; Bash, settings and the owner's editor never pass through it.

**Why.** ADR-0006 closes the hook "when the daemon is unavailable", yet no daemon exists: read literally the gate never opens, and task approval binds no agent write (08 s3 AC-4).

**Cost.** One process per agent write in every project with the plugin; the owner's own sessions are gated too (recovery: claim an approved task, `mode = "off"`, disable the plugin); a subagent in another worktree is refused; writers outside the hook pass; a hook timeout, a non-2 failure or a stray `allow` would open it, so a wrapper maps every failure to 2.
