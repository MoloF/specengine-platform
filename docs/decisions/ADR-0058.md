# ADR-0058

**Decision.** Supersedes ADR-0017. Named people may work one board on a public URL: `specengine-http` gains a hub mode, entered by one flag, `--public-origin`, and by nothing else, so no pull and no `spec serve` makes a hub. A local daemon behaves as it did. A hub keeps SQLite; `spec`, the daemon and `specengine-mcp` stay one build per data directory, the premise three canon lines cited ADR-0017 for. ADR-0035 stands until `hub-confirm`.

**Why.** The owner cancelled the principle so that a team can work one board. The mode belongs to the process, which serves several `--root`; a key in `specengine.toml` reaches every developer through git and would turn a local daemon into a hub on a pull.

**Cost.** A second fence to keep beside the local one, and every later non-GET route refused until listed there. "None blocks" in the queue's known limits holds for a local daemon; a hub rests on RM-0064's dumps. One process is now a shared surface: until `scale-reads` a team waits behind O(n) reads. No PostgreSQL, so a hub stays one host.
