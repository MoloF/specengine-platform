# ADR-0008

**Decision.** The core has no subject-domain concepts; specifics live in `specengine.toml` and the importer; from Phase 1, at least two pilot projects of different nature.

**Why.** A core exercised on one project silently adapts to it.

**Cost.** An importer per pilot project from day one.
