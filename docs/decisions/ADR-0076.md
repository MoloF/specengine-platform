# ADR-0076

**Decision.** Amends ADR-0073. The chrome says Department, Task, Subtask and Agent task for a workspace, a card, a child card and a `T-` task; config keys, CLI, MCP and daemon text keep theirs, with no alias. A department stays a lens, never an entitlement, a control point or a filter hiding work; its statuses are its flows' columns, categorised by position. A `[[card.flow]]` may carry a `title`. A module is a root and its subtree, or a direction: `kinds`, no root, served by the config read and applied by the reads that take a kind; Flow takes rooted modules only. A hand-off names a department; the card carries a discipline the new-card rule places in one of its flows.

**Why.** The owner's words, with no key an older binary refuses at the top level; a direction is a module, so no new table; the core still names no trade (ADR-0008).

**Cost.** Two vocabularies, a person's and the tools'. Older binaries refuse `title` and drop every module on `kinds`, so ADR-0073's upgrade rule holds. Flow draws no kind direction.
