# ADR-0023

**Decision.** Pipeline roles and commands live in `.claude/`; all development runs through `/feature` and `/feature-saving`, the main session only orchestrates.

**Why.** Implementation and verification are done by different agents with different rights and write zones.

**Cost.** Every task costs several agent runs.
