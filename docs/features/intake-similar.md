# intake-similar: a create lists what it may repeat, and an exact twin waits to be named (RM-0059)

## Why

A writer's AI could propose "Rain ambience" beside an existing "Rain ambience", and nothing warned it: `create` only reserved IDs (`docs/canon/proposal-kinds.md` "Reservation"). Two live creates of the same thing both stored, and the owner found the twins in the Inbox. The intake already refused an item until its exact hits were named (`docs/canon/agent-intake.md` "Dedup"); a create had no such step.

Now a create's answer lists `similar` entries, each with its source and reason: an equal title, an alias equal to the title, a live create's or amendment's title, a search rank, shared link targets. Only the exact three gate: the create stores once each gating entry is named in `distinct_from`, and the answer suggests an update of the existing node. Search and neighbour entries advise. The engine finds candidates deterministically; the agent's own model judges them (no LLM inside). No ADR: a refusal that naming passes is no block (ADR-0012), kinds are opaque strings (ADR-0008), nothing new is stored (ADR-0001); vectors would need an ADR reversing 04 s2.1.

## Description and interactions

Each decision is canon now, in `docs/canon/proposal-similar.md`: D1 only the exact signals gate, D2 create only, D3 not stored is an answer, D4 nothing new stored, D5 keywords per call: "The step"; D6 one state, one list: "The probes"; D7 a hub's own store, D8 plugin 0.42.0: "MCP, hub, plugin"; D9 the UI's one typed key: "Document and text"; D10 measured, never asserted: "Measured".

The owner's questions, open, their working answers built: **Q-A** search and neighbour entries never gate; **Q-B** `keywords` per call, no front-matter key (recall 80 % at 10k, over the 70 % that would reopen it); **Q-C** recall on planted collisions, his look at a pilot his own; **Q-D** an equal title of any kind gates; **Q-E** the queue probe outside the write lock, a known limit. The writer's W1 to W10 (the text line and head line, `null` in reviews, Tier 3 and the target never entries, the race, the caps 5, 5, 32, 1 000, 200 and 2, caps at step 1, unknown names ignored, the kind not narrowing the gate, short titles scanned, the UI line first) are in that canon too, W10 spent.
