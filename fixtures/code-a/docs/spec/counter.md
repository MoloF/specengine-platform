# Counter

A count that grows one step at a time and never passes its cap.

## Bound {#LAW-BOUND rev=2}

The count never exceeds the cap.

## Step {#LAW-STEP}

Each step adds one. The section writes no revision: it is at revision 1,
whatever its document's.

## Odd {#LAW-ODD rev=0}

A revision written but unreadable: a marker's revision meets none.
