# Командная строка

Инструмент синхронизирует рабочие копии; каждая команда отвечает одному
требованию REQ-001.

## Команда sync {#CMD-SYNC}

Команда `sync` сверяет рабочую копию с веткой (см. [[GLS-worktree|рабочая копия]]).
Вопрос ВОП-7 пока открыт.

### Флаг --dry-run {#FLAG-DRY-RUN rev=2}

Печатает план и ничего не пишет; см. CRIT-01 и RЕQ-003.

## Команда status {#CMD-STATUS}

Показывает состояние; прежнее описание было в ADR-0001#history.
