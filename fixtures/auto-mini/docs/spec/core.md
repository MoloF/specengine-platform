# Core rules

The two rules the auto-mode tests edit, each on lines of its own.

## Save slots {#R-01}

The game keeps three save slots.
A slot shows the time of its last save.

## Door timer {#R-02}

A door closes five seconds after the player passes it.
The timer starts again when the door opens.
