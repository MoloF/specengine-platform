# Lantern Keep

A small survival game: keep the lantern lit through the night while the
stamina economy pushes back.

## Pillars

- Every action costs stamina ([[DOM-MOVEMENT]]).
- Darkness is a resource, not a punishment.

## Core loop {#RULE-CORE-LOOP}

Gather oil, walk the walls, rest by the lantern. The loop follows R-12.
