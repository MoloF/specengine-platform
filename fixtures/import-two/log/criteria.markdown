# Criteria of the importer

1. __CRT-0001 -__ The importer reads every listed root.
   It never writes into them.
2. __CRT-0002__; The importer reports every skipped file.
3) __CRT-0003__ The importer stops at its budget.

## Budget {#DEC-0010}

The budget is set per run; see DEC-0001.
