# Valves

Valve rules of the greenhouse controller.

| Code | Rule |
|---|---|
| VLV-001 | A valve closes when the line pressure drops below the floor. |
| VLV-002 | A valve opens only inside its watering window. |
| VLV-004 | Each zone reports its valve count at start. |
| VLV-006 | The main valve opens last. |
| VLV-010 | The north zone has a valve of its own. |
| IRR-003 | A zone waters at most twice a day. |
