# Schedule

| Code | Rule |
|---|---|

| IRR-005 | The schedule starts at dawn. |
| WTR-007 | A zone skips its turn after rain. |
| IRR-008 | Frost closes every valve. |
| IRR-009 | Frost delays the schedule by one hour. |
