# Hiring a bicycle

Riders hire a bicycle at a street dock, ride it, and return it to any dock
with a free slot.

## Unlock {#JRN-UNLOCK}

The rider scans the dock code; the slot releases the bicycle within two
seconds. A dock that cannot release it says so and charges nothing.

## Return {#JRN-RETURN}

The rider pushes the bicycle into a free slot; the ride ends when the slot
locks. A full dock shows the nearest dock with a free slot.
