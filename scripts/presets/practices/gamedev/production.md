# Production: agreed rules

The production department's agreed rules for planning and deciding. A task card of the `production` discipline carries them as its practices; cite a rule by its ID when a plan keeps or departs from it.

## An estimate backs its argument {#PRA-PROD-ESTIMATES}

An estimate names what it rests on: the comparable work it was measured against, the people it assumes and the risks left out. A range is given when the work is new; a single number only when the same work was done before.

## A decision is recorded {#PRA-PROD-DECISIONS}

A decision that changes scope, schedule or a department's rules is recorded where the team reads it, with the options weighed and why this one was taken, before the work it changes starts.

## A scope cut names the cost {#PRA-PROD-SCOPE}

A cut names what the player loses, which cards and documents it closes, and what it frees. Nothing is cut silently: the departments whose work it touches see it before it lands.
